# 📱 Discipline OS

A minimal, distraction-free personal productivity app designed for real daily use.

The goal is simple:
👉 Open → mark tasks → close
No clutter. No overthinking.

---

## 🚀 Features

### ✅ Daily Task Tracking

* Tap to mark tasks as done
* Supports:

  * Binary tasks (done / not done)
  * Numeric tasks (e.g., water intake, steps)
  * Frequency-based tasks

---

### ⏰ Time-Based Logic

* Morning tasks disappear after time window
* Night tasks appear later in the day
* Missed tasks are:

  * Striked through
  * Locked for that day
* Late completion is allowed (optional)

---

### 💊 Medicine Tracking

* Daily medicines
* Multiple times per day (e.g., twice daily)
* Interval-based (e.g., every 3 days)

---

### 📊 Progress System

* Score out of 100 based on completed tasks
* Partial scoring (e.g., 5k steps = half points)

---

### 📘 Built-in Routines (Knowledge Section)

* Skincare
* Haircare
* Workout
* Diet
* Career / Study plan

👉 Tap any task → view routine instantly
No need for external docs

---

### ⚙️ Custom Task System

* Add / edit / delete tasks
* Choose task type:

  * Boolean
  * Numeric
  * Interval
* Configure:

  * Target values
  * Points
  * Time window

---

### 📅 History Tracking

* View past performance
* Track consistency over time

---

## 🎯 Design Philosophy

* Minimal UI
* Zero friction
* Built for **real life usage**, not aesthetics
* Everything accessible in **< 2 taps**

---

## 📱 Usage
